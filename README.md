# Website POUK Wasuponda (frontend v0.1)

Next.js 15 + TypeScript + Tailwind CSS 4. Belum ada backend; semua konten ada di `src/lib/data.ts`.

    npm install
    npm run dev      # http://localhost:3000

Sebelum rilis, ganti data contoh di `src/lib/data.ts`: nomor WhatsApp, alamat, jadwal ibadah, warta, renungan, kegiatan, kesaksian, dan jawaban FAQ.
